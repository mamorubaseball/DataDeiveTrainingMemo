最初から機能まで作らせるのではなく、まずは「モック（画面遷移だけ）」を作るのがおすすめです。

今回は React Native + Expo がベストだと思います。

理由

iOSシミュレータですぐ確認できる
将来的にAndroid対応も可能
Apple Health連携は後から追加可能
React Native ReanimatedでLiquid Glassのようなアニメーションも作りやすい
Cursor / Claude Codeとの相性が良い
開発指示書（v0.1 Mock作成）
# プロジェクト

データドリブン筋トレアプリのUIモックを作成してください。

目的は実装ではなく、
「画面遷移」と「UIデザイン」の確認です。

技術スタック

- React Native
- Expo
- TypeScript
- Expo Router
- React Native Reanimated
- react-native-svg
- react-native-chart-kit（仮）
- react-native-calendars
- React Navigation（Expo Router利用時は不要な箇所のみ）
- Zustand（状態管理）
- NativeWind(Tailwind)

データはすべてダミーデータで構いません。

今回は

実装不要。

API不要。

DB不要。

Apple Health不要。

ダミーデータのみ。

目的は

デザイン品質

画面遷移

UX確認。

コンポーネントは再利用可能な構成にし、フォルダ構成も実運用を意識してください。
追加でおすすめしたいこと

このプロジェクトは将来的にかなり大きくなるので、Feature First構成を採用することをおすすめします。

src/
 ├── app/                # Expo Router
 ├── features/
 │    ├── home/
 │    ├── workout/
 │    ├── analytics/
 │    ├── ai/
 │    ├── profile/
 │    └── health/
 ├── components/
 │    ├── ui/
 │    ├── charts/
 │    ├── cards/
 │    └── calendar/
 ├── services/
 ├── hooks/
 ├── stores/
 ├── types/
 ├── constants/
 └── assets/

この構成なら、将来の Apple Health連携・AIチャット・SQL分析・筋トレマッチング機能 を追加しても破綻しにくく、長期運用しやすいアプリになります。
